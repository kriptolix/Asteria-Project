{# Generic content card. `item` can be a post, a page, or any object/dict that exposes at least `title` and `url` — every other field is optional and simply skipped when falsy, so the same macro works for posts, pages, or a hand-authored list of dicts alike. Fields read from `item` (all but title/url are optional): item.title -> card heading, and the card's link text item.url -> link target for the whole card item.image -> cover image URL item.image_alt -> alt text for the cover image item.date -> passed through the site's format_date filter item.lang -> language for format_date (falls back to page.lang) item.author -> shown next to the date item.excerpt -> short summary text (clamped to 3 lines in CSS) item.tags / item.categories -> rendered as the same pill links post.html uses The whole card is clickable via a "stretched link" on the title (see .card__title a::after in light.css) rather than wrapping the image in a second, redundant link — one real link per card, better for keyboard/screen-reader users, larger click target for everyone. #} {% macro render_card(item) %}
